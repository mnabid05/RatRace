# RatRace

Unreal Engine 5.8 project.

## Open the project

1. Install Unreal Engine 5.8.
2. Clone this repository.
3. Open `Rat_Race.uproject` in Unreal Editor.
4. Open `Content/ThirdPerson/Lvl_ThirdPerson` and press Play.

The repository includes the project descriptor, configuration, and content assets. Unreal regenerates caches and intermediate files locally.

Android File Server is disabled in the shared configuration; its local security token is not included.
